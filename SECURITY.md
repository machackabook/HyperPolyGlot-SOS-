# Security

No secrets in the tree. Tokens and keys live only in GitHub Secrets or local untracked environments.

- Do not commit `.env`, Tailscale auth keys, ADB pair codes, or device credentials.
- `.env.example` contains placeholders only.
- A found key is a stop, not a stamp. Missing keys are the correct state.
- This repository does not claim a device was rooted.
- Source code is the only trusted neighbor.
